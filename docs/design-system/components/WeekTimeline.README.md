# WeekTimeline

The 13 weeks of a live quarter: done weeks filled with `ink`, the current week outlined, future weeks sunk.

- **Props:** `current` (1–13), `interrupts` (week numbers with an alert; they get an `accent` notch above).
- It advances one cell per ~1.5 seconds at 1×. Under reduced motion, cells change with no transition.
- Pair it with the Segmented speed control (Pause · 1× · 2× · Skip).
