# PlanEras

The Plan dashboard in the `bedroom` era (Prologue, Q3 2011) next to `garage` (Act I, Q3 2018). It is a proof screen for the handover: the two should read as the same notebook a few years apart.

- Built only from the system's components. Each half sets `data-theme` on its own frame, so both eras render on one page.
- What carries over: ink, fonts, figures, gain and loss, radii, the ink primary button, the layout.
- What changes in bedroom: warmer paper with a 12px graph-paper grid, dashed panel rules, the muted green accent on the hashprice series and title rules, display titles one weight lighter, and up to two tape notes per screen.
- The Prologue player figures (cash, income, custody split, Heat) are a sample state, not balance values. The market figures come from the Prologue data (`market_quarterly_prologue.csv`): BTC closed Q3 2011 at $5.28, down 62% on the quarter, and hashprice fell 82%. Solo odds are that data's network hashrate against 394 MH/s.
