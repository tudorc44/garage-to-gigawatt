61 line icons on a 20px grid, 1.5px stroke, round caps and joins, no fills except small dots. Single ink: #1E2A44 (`ink`, Garage era). Because an `<img>` can't inherit colour, in the game prefer the Icon component (`<Icon name="scout" />`), which draws the same shapes with `currentColor` and so follows each era's ink. Use these files only where a component can't go (docs, store pages, a favicon sheet).
