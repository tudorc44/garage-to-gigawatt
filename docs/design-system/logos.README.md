The mark and every app icon, as SVGs drawn on a 64-unit grid in `brand-yellow` #FFC400 and `brand-black` #121212 (no fonts, no gradients).

- **mark.svg:** master mark with hazard band (social avatars, loading screen, press kit).
- **mark-plain.svg:** no band (tight spots).
- **favicon-16.svg, favicon-32.svg:** browser tab. Small drawing, no band.
- **favicon-48.svg:** Windows and site icons.
- **apple-touch-icon-180.svg:** iOS home screen, full-bleed.
- **icon-192.svg, icon-512.svg:** web manifest icons. The 512 is also the itch.io game icon.
- **icon-maskable-512.svg:** Android adaptive icon (manifest `"purpose": "maskable"`); the G and bolt sit inside the central 80% safe circle.
- **explore-a-g2g.svg, explore-b-bolt-g.svg, explore-c-pylon.svg:** the three mark explorations, kept for the record. B is the chosen mark. Don't use A or C.

Export to PNG at 1× the file's size for platforms that don't take SVG.
